Now that two-source interference feels less mysterious, we can connect it to a deeper statement: the Huygens principle. The punchline is that every point on a wavefront can be treated as a little source, and the full wavefront at a later time is what you get when you add all of these tiny contributions together.

This sounds abstract until you actually increase the number of sources. Then the pattern suddenly stops feeling like a toy and starts looking like a structured wavefront again, and that is exactly the moment where many people realize that interference is not a special case but the default behavior of wave propagation.

If the little contributions align, amplitudes reinforce each other; if they oppose, amplitudes cancel. You have already seen this for two sources, but with many sources the same rule builds full fronts, directional patterns, and eventually diffraction structure.
