# biosbi Playground

This page is intentionally simple: write notes as markdown, then use the embedded tools to interact with local services.

## Why this exists

- quick local interaction for simulation workflows
- editable JSON parameters for forward simulation
- easy handoff to a local process via HTTP

## Usage pattern

1. Edit the simulation parameters and save them.
2. Add markdown notes for the current run.
3. Send short JSON payloads to your local program.
